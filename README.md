# Jejari Kopi 3D - WebXR Scene

**Nama:** Rajif Fandi
**NIM:** 2305010041
**Mata Kuliah:** Pengembangan Game dan Teknologi Immersive

## Deskripsi Tema
Scene 3D interaktif bertema kedai kopi ("Jejari Kopi"). Terdapat 5 objek 3D dengan geometri berbeda (Box, Cylinder, Torus, Sphere, Cone) yang merepresentasikan meja bar, cangkir kopi, donat, biji kopi raksasa, dan alat seduh corong V60. Seluruh objek menggunakan MeshStandardMaterial dengan variasi roughness dan metalness.

## Cara Menjalankan
1. Buka URL Live GitHub Pages berikut:(https://rajif-fandi.github.io/tugas-threejs-rajif/) 
2. Putar kamera menggunakan mouse (klik kiri tahan dan geser).
3. Scroll untuk Zoom In/Out.
4. Arahkan kursor (hover) ke objek di atas meja untuk melihat efek menyala (emissive) dan kursor berubah menjadi pointer.
5. Klik kiri pada objek untuk membesarkan ukuran dan melihat informasi objek di pojok kiri atas.
